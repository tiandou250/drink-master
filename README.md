# 饮料小当家 · Drink Master

市面主流奶茶与咖啡的爆款饮品，拆成家里能做的配方。

有分层图、具体用量、分步做法和避坑提示——**不是官方配方，是家庭条件下的还原版**。

## 本地打开

**直接双击 `index.html` 就能用。** 不需要安装任何东西，不需要构建，不需要起服务器。

这是因为数据存成 `.js` 而不是 `.json`——如果用 JSON + `fetch`，双击打开会被浏览器的 CORS 拦掉，页面直接白屏。

## 加一款新饮品

在对应的 `data/*.js` 里追加一条：

```js
{
  id:'wei-yi-biao-shi',        // 唯一，英文或拼音
  name:'饮品名',
  category:'咖啡',              // 咖啡|奶茶|轻乳茶|果茶|柠檬茶|特调|小料
  brands:['品牌A','品牌B'],
  method:'分层',                // 直调|分层|摇匀|打沙|需煮|打泡|浸泡
  difficulty:1,                 // 1-3
  temp:'冰',                    // 冰|热|冷热皆可
  volume:500,
  bg:'#FCD34D',                 // 卡片底色，同品类内别重复
  nocaf:true,                   // 可选：不含咖啡因才写
  layers:[                      // 分层图，pct 之和会自动归一化
    {name:'浓缩咖啡', pct:25, color:'#6F4E37'},
    {name:'厚椰乳', pct:75, color:'#F0DFC8'}
  ],
  intro:'一句话说清这杯的特点或难点。',
  ingredients:[
    {name:'厚椰乳', amount:'200ml', note:'替代方案写这里'},
    {name:'糖浆', amount:'10ml', optional:true}
  ],
  tools:['杯子','勺子'],
  pitfalls:['容易做错的第一点。','第二点。'],
  fidelity:'和店里的差别在哪。',
  steps:[
    {title:'步骤标题', desc:'具体怎么做。', act:'倒入',
     add:[{name:'厚椰乳', pct:36, color:'#F0DFC8'}]},   // add 决定这一步杯子变成什么状态
    {title:'需要等待的步骤', desc:'...', timer:180, act:'加热'}  // timer 单位秒
  ]
}
```

改完跑一下校验：

```bash
node scripts/check.js
```

会检查字段完整性、id 唯一、用量是否写了「适量」、配色在同品类内是否重复。

## 内容规范

这个库的质量靠三条红线撑着，加新配方时请保持：

1. **禁止「适量」「少许」「若干」**——一律换算成 g / ml / 颗。网上配方失败率高，八成死在「适量」两个字上。
2. **一步只讲一个动作**——「倒入椰乳并搅拌均匀」要拆成两步。
3. **需要等待就必须给 timer**——泡茶 3 分钟、摇 15 秒、焖 10 分钟。

另外每条都要有 `fidelity` 说明和店里的差别。**不假装是官方配方。**

## 配色

界面是黑白灰，只有饮品本身有颜色。卡片底色取自 Tailwind 色板，按品类划分色相区段：

| 品类 | 色相 |
|---|---|
| 咖啡 | 琥珀 / 橙 / 黄 |
| 奶茶 | 橙红 / 玫瑰 / 粉 |
| 轻乳茶 | 青 / 蓝绿 |
| 果茶 | 紫 / 粉 / 玫红 |
| 柠檬茶 | 绿 / 黄绿 |
| 特调 | 蓝 / 靛 |
| 小料 | 中性灰 |

**同品类内不重复，跨品类可以重复**——因为用户筛选后看到的是同一品类。

## 技术

纯原生 HTML + CSS + JS。无框架、无依赖、无构建、无后端。

- 分层图由 `layers` 比例实时计算生成 SVG，零图片资源
- 制作页每一步的杯子状态由前面所有步骤的 `add` 累积得出
- 备料勾选状态存在内存中，页面刷新会重置
- 完成页的烟花是 Canvas 方块粒子
